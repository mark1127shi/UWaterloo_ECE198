# UWaterloo_ECE198
This is the repository for ECE198 Group 008
## Hardware
We have tested different parts of our ardurino and those modules.

In this project, we have:
| Component | Quantity | Purpose |
| --- | ---: | --- |
| Arduino UNO R4 | 1 | Reads the sensor and runs the workout timer and rep counter |
| ADXL335 three-axis accelerometer breakout | 1 | Measures arm movement |
| 16×2 LCD with I²C backpack (LCD1602) | 1 | Displays workout progress, prompts, and rest countdowns |
| Momentary push buttons | 2 | START/RESUME on D7 and PAUSE/LOG on D8 |
| Solderless breadboard | 1 | Connects components and distributes power and ground |
| Jumper wires | 1 set | Connects the Arduino, breadboard, sensor, buttons, and LCD |
| USB-C data cable | 1 | Powers the Arduino and uploads the firmware |
| Two-axis analog joystick module with push switch | 1 | Navigates the LCD menu and selects a mode |
| Green LED | 1 | Indicates that a workout is active |
| Red LED | 1 | Indicates that a workout is paused |
| 330 Ω resistors | 2 | Limits LED current, one resistor per LED |
